# 🚀 DriveMindscape
**A Multimodal Cognitive Driving Dataset with Aligned Cognition and Behavior**
<div align="center">

---

## 🌟 About the Dataset
**DriveMindscape** is a novel multimodal driving dataset that integrates human behaviors, eye-tracking data, psychophysiological states, and real-time cognitive narrations collected from 34 subjects under carefully designed critical traffic scenarios[cite: 1, 7, 8]. 

Current autonomous driving datasets typically lack multi-dimensional cognitive evidence chains (encompassing physiological, mental, and behavioral modalities)[cite: 1, 8]. DriveMindscape bridges this gap by offering rigorous human-in-the-loop experiment data, providing robust support for interpretable white-box driver cognitive modeling and human-factor safety analysis in long-tail scenarios[cite: 1, 7, 8].

The dataset is publicly available at [this link](https://drive.google.com/drive/folders/19-xw9y8q8kv1JqhTRxBfeI32vovKEE5s?usp=sharing).

## ✨ Key Features

- **Multimodal Alignment**: Synchronizes vehicle sensors, control behaviors, eye-tracking vectors, and emotional scales (SAM & DES).
- **Critical Scenarios**: Focuses on high-risk safety events (highway cut-ins, blind-spot pedestrian crossings, and multi-vehicle lane-changing games) designed to induce rich cognitive behaviors.
- **First-Person Cognitive Narrations**: Captures genuine decision-making thought processes via post-experiment interviews and Critical Decision Methods (CDM), avoiding synthetic/post-hoc bias.
- **White-Box Cognitive Support**: Accompanied by formalized ACT-R knowledge chunks and production rules to bridge the gap between internal reasoning and observable actions.
